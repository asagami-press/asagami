# 朝刊 紙面アーカイブ（asagami）

リハ医療デイリー／テックデイリーの朝刊 **紙面 PDF** を日付ごとに置く配信用リポジトリです。
索引ページ: https://asagami-press.github.io/asagami/

## URL の形

```
https://asagami-press.github.io/asagami/                          # 索引（最新号＋過去の紙面）
https://asagami-press.github.io/asagami/<YYYY-MM-DD>/             # その日の号ページ（2 面の紙面画像・PDF・原典リンク）
https://asagami-press.github.io/asagami/<YYYY-MM-DD>/medical.pdf  # 医療面（リハ医療デイリー）
https://asagami-press.github.io/asagami/<YYYY-MM-DD>/tech.pdf     # テック面（テックデイリー）
```

- 1 面 1 ページ（2160×4320 相当）。見出し・出典は PDF 内リンク。`.webp` は紙面画像の Web 用縮小版（幅 1080）。
- このリポジトリに入るのは紙面 PDF・紙面画像と索引（index.html / style.css / 号ページ）だけ。生成スクリプト・台帳・下書きは含みません。
