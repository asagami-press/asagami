# 朝刊 紙面アーカイブ（asagami）

リハ医療デイリー／テックデイリーの朝刊 **紙面 PDF** を日付ごとに置くだけの配信用リポジトリです。
索引ページ: https://koji1226.github.io/asagami/

## URL の形

```
https://koji1226.github.io/asagami/<YYYY-MM-DD>/medical.pdf   # 医療面（リハ医療デイリー）
https://koji1226.github.io/asagami/<YYYY-MM-DD>/tech.pdf      # テック面（テックデイリー）
```

- 1 面 1 ページ（2160×4320 相当）。見出し・出典は PDF 内リンク。
- このリポジトリに入るのは紙面 PDF と索引（index.html）だけ。生成スクリプト・台帳・下書きは含みません。
